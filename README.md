# Kimia Sinaeian — academic website

Source for [kimiasinaeian.github.io](https://kimiasinaeian.github.io), an academic website built with the [Academic Pages](https://academicpages.github.io/) Jekyll template and hosted by GitHub Pages.

Site content is maintained in Markdown. The homepage and CV live in `_pages`, publications live in `_publications`, and site-wide settings are in `_config.yml`.
